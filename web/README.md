# MAY去哪啊 · 网页版

这是独立维护的网页版项目。小程序保留在上一级目录，网页版不读取或修改上一级项目文件。

- `source/`：2026-10-27 从小程序复制的代码、资源和数据快照，后续网页版所需修改只在此副本进行。
- `dist/`：可发布的手机端网页，使用副本中的小程序首页和分析页布局、样式及业务代码。
- `build.cjs` / `build-mobile.cjs`：只从本项目的 `source/` 打包页面、样式及依赖。
- `dist/mobile.js`：浏览器适配层，包括页面渲染、跳转、存储、请求及图表绘制。
- `.openai/hosting.json`：网页版独立的网站发布配置。

在此目录运行 `node build.cjs`，更新网页数据。无需小程序项目即可运行。

小程序与网页版后续各自开发，不自动同步代码或数据。当前网页最新报价仍读取原有 Cloudflare 公共报价服务；这属于共用后端服务，不是源码依赖。后续针对网页版修改接口时，应建立独立服务，避免影响小程序。

网页版专注手机端，不提供单独的 PC 布局。支持与小程序一致的中英文切换、目的地搜索弹窗、单程/往返、币种选择、完整分析图表及云端样本合并。浏览器补充返回首页及复制链接操作。已在 390×844 浏览器尺寸验证以上主要流程；发布状态以 Sites 返回结果为准。
