# 数据来源与解释

数据详表见 `price-intelligence/README.md`、各航线的 `route.json` / `observations.json`，以及往返目录说明。原币种、来源 URL 和采集日期应与报价一起保留。

记录分为公开报价、已过出发日期的历史公开报价、以及来源页面自述的订单或付款记录。最后一类不代表项目独立核验了旅客、订单或付款。采集不访问用户私有订单，不绕过登录、验证码或访问控制。

每日零点是任务触发时间；来源页面按七天轮换，不能解释为每天检查所有来源。Cloudflare KV 的线上增量状态未包含在仓库快照中。旧归档也不代表最新报价。

币种显示基于 `utils/currency-config.js` 中带日期的参考汇率快照，不应称为实时汇率。没有足够样本的路线保留缺失状态，不推断价格。
